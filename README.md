# 🏗️ Grewal Concrete and Carpentry

**Official website for Grewal Concrete Pty Ltd** — a Melbourne-based concreting and carpentry business serving builders and homeowners across Victoria's northern growth corridor.

🔗 **Live site:** [grewalconcrete.com.au](https://grewalconcrete.com.au)

---

## 📋 About

Grewal Concrete and Carpentry has been delivering quality concrete and carpentry work since 2021, working alongside some of Melbourne's leading builders including **Henley Homes**, **Simonds Homes**, and **Nostra Homes**.

Founded by **Harry Grewal** — a certified carpenter with 8 years of hands-on experience in concreting — the business specialises in:

- 🧱 Concrete slabs
- 🏖️ Sand slabs
- 🪵 Frames
- 🔲 Formwork
- 🚗 Driveways
- ⛏️ Excavation
- 🔩 Piers
- 🧰 Base / pre-slab preparation

This repository contains the source code for the company's marketing website — a fast, simple, front-end-only site built to showcase the business, its services, and completed projects.

## 🚀 Getting Started

Since this is a static site, there's nothing to install or build. To run it locally:

```bash
git clone https://github.com/somilror200/grewal-construction-website.git
cd grewal-construction-website
```

Then simply open `index.html` in your browser — or use a local server:

```bash
python3 -m http.server
```

and visit `http://localhost:8000`.
