- About

## Build

The site is intentionally lightweight:

- Semantic HTML
- Responsive CSS
- Vanilla JavaScript
- No framework or build step
- GitHub Pages compatible

The 2026 rebuild uses the company's existing content, original logo files, favicon set, fleet/equipment photography, and project photography. All existing image assets remain referenced by the site.
